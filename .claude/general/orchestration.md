# オーケストレーション（常時）

メイン（Fable 5.1）がオーケストレータ、Opus 5.5 のサブエージェント（`.claude/agents/`、model はフル ID `claude-opus-5-5` で固定）が実作業を担当する。

- 役割: オーケストレータ = 計画・タスク分解・依頼文・結果の確認と統合・コミット・ユーザーへの報告。`worker` = 実装・テスト（ファイル変更あり）。`researcher` = 調査・原因分析・公式ドキュメント（読み取り専用）。`reviewer` = worker の成果の検証（読み取り専用）。
- 依頼: 1 タスクごとに目的・変更してよいファイル・完了条件（通すべきテスト）・検証方法を明示する。
  - 並列に渡すのは、互いに依存せず変更するファイルが重ならないタスクだけ（重なるなら順番に渡すか 1 つにまとめる）。
  - 調査が先に要るなら researcher を並列で投げ、結果を待ってから worker を起動する。単発のファクト確認（1 ファイル・1 シンボル）は委譲せず自分で見る。
- 結果の確認: worker の報告を鵜呑みにしない。reviewer に検証させるか、自分でテスト実行・差分確認をしてから統合・報告する。報告は各定義の報告フォーマットで短く返させる（メインのコンテキストに戻るため）。
- 禁止: サブエージェントの git commit / push / PR 作成 / マージ。PreToolUse フック `scripts/hooks/guard-git.sh`（`.claude/settings.json`）が `agent_type` で判定して拒否する。
