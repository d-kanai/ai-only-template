- 理由: daiki の「本番は private にするから有料ならいらない」「Lint とか静的解析で十分では」。private の repo の CodeQL は有料（GitHub Code Security）。コードの書き方は Biome（pre-commit・CI）と日次の Claude セキュリティレビューで見る。依存の既知の脆弱性は lint で見つからないので、無料の pnpm audit は残すよう提案した。#112 のスレッドにはコーディネータ経由で伝えた。
- 根拠: CodeQL が private の repo で有料なことは GitHub の料金体系の知識で、今回は未確認（#112 のスレッドで確かめる）。
- 機械化: 対象外（判断のみ）
