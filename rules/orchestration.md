# オーケストレーションルール

メイン（Fable 5.1）がオーケストレータ、Opus 5.5 のサブエージェントが実作業を担当する。
サブエージェントは `.claude/agents/` に定義し、model はフルID `claude-opus-5-5` で固定する。

## 役割
- オーケストレータ: 計画、タスク分解、依頼文の作成、結果の確認と統合、コミット、ユーザーへの報告。
- `worker`: 実装、テスト作成・実行などの実作業。ファイル変更あり。
- `researcher`: コードベース調査・原因分析・公式ドキュメント調査。読み取り専用。
- `reviewer`: worker の成果の検証。読み取り専用。

## 依頼の仕方
- 1タスクごとに、目的・変更してよいファイル・完了条件（通すべきテスト）・検証方法を明示して渡す。
- 互いに依存せず、変更するファイルが重ならないタスクだけを並列で渡す。重なる場合は順番に渡すか1つの worker にまとめる。
- 調査が先に必要なら researcher を並列で投げ、結果を待ってから worker を起動する。
- 単発のファクト確認（1ファイル・1シンボル）は委譲せず自分で見る。

## 結果の確認
- worker の報告を鵜呑みにしない。reviewer に検証させるか、オーケストレータ自身がテスト実行や差分確認で事実を確認してから統合・報告する。
- サブエージェントの報告はメインのコンテキストに戻るため、報告は各定義の報告フォーマットに従って短く返させる。

## 禁止
- サブエージェントによる git commit / push。
